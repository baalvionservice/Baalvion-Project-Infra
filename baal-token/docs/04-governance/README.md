# 04 Governance

v1 has **no on-chain governance** and no governance token features: BAAL is a plain SPL token and there is no program to govern.

## Decisions that exist today

Phase 0 decisions are recorded as ADRs. Changing any of them requires a new ADR with founder approval.

## Open decisions (not yet made)

- Who may approve changes to allocation, vesting and custody arrangements after launch.
- Treasury is designed as a 3-of-5 multisig with at least one independent signer ([ADR-009](../01-architecture/adr/ADR-009-treasury-multisig.md)); signers, independence count and mechanism are undecided.
- How decisions are published for transparency ([13-transparency](../13-transparency/README.md)).
- Whether any off-chain governance process will exist. None is promised.
