# 00 Overview

BAAL is a global token associated with the broader Baalvion vision. It is designed to be as simple and inspectable as a token can be: a standard Solana SPL token with a fixed supply and no special authorities.

## Approved decisions (Phase 0)

Classic SPL Token; 1,000,000,000 total supply; 9 decimals; fixed supply; mint authority permanently revoked; no freeze authority; no public sale in v1; no custom smart contract in v1; informational website only (no wallets, no transactions). Allocation percentages and the founder/team vesting are in [03-tokenomics](../03-tokenomics/README.md).

## What BAAL is not

BAAL does not represent equity, ownership, revenue rights, or assets of Baalvion unless a future legally valid structure explicitly establishes such rights. The project makes no price promises or return guarantees and will not use fake activity, partnerships, users or volume, wash trading, or market manipulation.

## Current state

Phase 1: repository, validators, tests, safety guards and a website skeleton exist locally. No token, wallet, keypair, liquidity or deployment exists. See [10-roadmap](../10-roadmap/README.md).
