# 12 Incident response (draft)

Because there is no freeze authority and the mint authority will be revoked, **the chain state cannot be paused or corrected**. Response is containment and communication.

Draft playbook headings (to be completed before launch): key compromise (rotate multisig signers, move funds, publish notice); phishing/impersonation (takedown, official warning, verify page); website compromise (take site down, restore from reproducible build); leaked secret (revoke, rotate, history scrub, notify); wrong launch parameter (cannot be fixed by supply change; communicate; new-mint decision).

Contacts, severity levels and on-call: undecided. Security reports address: not yet published.
