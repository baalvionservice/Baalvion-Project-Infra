# 13 Transparency

Commitments to be fulfilled at and after launch:

- Publish mint address, launch transaction, authority status and all allocation wallet addresses on the verify page.
- Publish the allocation and vesting schedule (already generated from `allocation.json`) and any change to it, with reasons.
- Publish treasury movements.
- Never present unverified numbers: unknown values stay visibly marked as unknown or pending (as the TGE circulating supply is today).
- Never fabricate users, partners, volume or activity.
