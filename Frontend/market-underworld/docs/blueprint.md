# **App Name**: Market Under World

## Core Features:

- Comprehensive UI Component Library: Develop all specified production-ready, fully styled UI components, including Buttons, Cards, Badges, Inputs, Navigation, Modals, Data Display, and Layout Components, adhering to elite quality standards.
- Mock Data Integration System: Implement a system to load, manage, and present all specified mock JSON data (regions, teachers, students, products, forum posts) for application content, serving as the sole data source.
- Advanced UI Effects & Animations: Integrate global visual effects and animations using Framer Motion, such as smooth page transitions, hover micro-interactions, gradient text, glassmorphism, background particles/grids, a scrolling crypto price ticker, and pulse/shimmer animations.
- Responsive Layout & Navigation System: Establish a robust and fully responsive (mobile, tablet, desktop) layout and navigation foundation, including page wrappers, section headers, various grid layouts, and custom routing with React Router for all specified pages.
- Design System Showcase Page: Create a dedicated '/design-system' page to visually display and document every developed UI component, demonstrating their functionality, states, and adherence to style guidelines.

## Style Guidelines:

- Strictly dark mode UI, with a premium and futuristic aesthetic. The primary background is near black (#0A0A0F), complemented by secondary background (#111118) and card backgrounds (#16161F).
- Vibrant electric purple (#6C63FF) serves as the primary accent, reflecting innovation and interactivity, with a striking cyan blue (#00D4FF) as a secondary accent and a coral pink (#FF6584) for tertiary use or alerts.
- Text colors maintain hierarchy with pure white (#FFFFFF) for primary content, muted secondary text (#A0A0B8), and very subtle tertiary information (#5A5A7A).
- Gradients define key interactive elements and VIP features, including a blend from electric purple to cyan blue, and a dynamic coral pink to warning yellow.
- Semantic colors are clearly defined for success (#00E676), warning (#FFD600), and error (#FF3D57) states to convey immediate feedback.
- Headlines are set in 'Space Grotesk' (sans-serif), with various bold and semibold weights defining visual hierarchy across display and heading sizes (Display 72px bold, H1 48px bold, H2 36px semibold, H3 24px semibold, H4 20px medium).
- Body text utilizes 'Inter' (sans-serif) for optimal readability in varying contexts and lengths (Body Large 18px regular, Body 16px regular, Small 14px regular, Micro 12px regular). Code snippets and monospaced content will use 'JetBrains Mono' (monospace). Note: currently only Google Fonts are supported.
- A cohesive icon system will feature modern, sharp vector icons to align with the futuristic theme. Distinctive icons will be used for specific elements like crypto indicators (BTC/ETH/USDT), regional identifiers, status badges (Live, VIP, Active/Inactive/Pending), and general interactive elements.
- A fully responsive structure optimized for mobile, tablet, and desktop, incorporating predefined max-width containers and consistent padding for page wrappers. Content will be organized using responsive grid layouts (2, 3, and 4 columns).
- Navigation elements include a glassmorphic Top Navbar, a collapsible Sidebar, a breadcrumb component, tab bars with gradient active indicators, and a dedicated mobile bottom navigation for an intuitive user experience.
- Framer Motion powers all animations for smooth and engaging interactions, including fluid page transitions (fade + slide), subtle hover micro-interactions on all cards, and shimmer loading skeletons for dynamic content.
- Key dynamic visual elements feature gradient text for major headings, a particle or grid background for hero sections, a persistent scrolling crypto price ticker at the top of the page, and a pulsing animation for 'LIVE' badges.
